    API Reference

    The public API is importable from the gbq package:

    from gbq import BigQuery, GbqException, InvalidDefinitionException

    BigQuery

    BigQueryUtil represent a BigQuery Util resource.

    Authentication uses, in order of precedence: credentials, then svc_account, then Application Default Credentials (for example Workload Identity, an attached service account, GOOGLE_APPLICATION_CREDENTIALS, or gcloud auth application-default login). Prefer credentials or Application Default Credentials over long-lived service account keys.

    Parameters:

    Name Type Description Default
    svc_account Optional[str]

    Stringified JSON service account key.

    		 None
    project Optional[str]

    Project bound to the operation.

    		 None
    credentials Optional[Credentials]

    Credentials to use, e.g. from google.auth.default() or impersonation.

    		 None

    Raises:

    Type Description
    GbqException

    If both svc_account and credentials are given, or if svc_account is not a valid service account key.

    create_or_update_structure(project, dataset, structure_id, json_schema)

    Function creates/updates provided json schema to the structure.

    Parameters:

    Name Type Description Default
    project str

    Project bound to the operation.

    		 required
    dataset str

    ID of dataset containing the structure.

    		 required
    structure_id str

    ID of the structure.

    		 required
    json_schema Union[List[Dict], Dict]

    Raw JSON schema of the table. If List[Dict] it is assumed that the value is table schema, if Dict than value can include partitioning scheme, clustering, table schema, view query, labels, etc

    		 required

    Examples:

    List[Dict]: [ { "name": "name1", "type: "INTEGER", "mode: "REQUIRED" }, { "name": "name2", "type: "STRING" }... ]

    Dict: List[Dict]: { "clustering": ["name"], "partition": { "type": "time", "definition": { "type": "DAY" } }, "description": "this is a partitioned table", "labels": {"team: "abc"}, "schema: [ { "name": "name1", "type: "INTEGER", "mode: "REQUIRED" }, { "name": "name2", "type: "STRING" }... ] }

    Returns:

    Name Type Description
    Table Table | Routine

    An object of BigQuery Table.

    execute(query, query_parameters=None, job_config=None, *, project=None)

    Function return a QueryJob object after executing a SQL statement

    Pass untrusted values as query_parameters and reference them in the query as @name, rather than formatting them into the query string, to avoid SQL injection.

    Parameters:

    Name Type Description Default
    query str

    BigQuery query string

    		 required
    query_parameters Optional[Sequence[QueryParameter]]

    Parameters referenced by the query, e.g. bigquery.ScalarQueryParameter("name", "STRING", value).

    		 None
    job_config Optional[QueryJobConfig]

    Extra job settings such as labels, dry_run or maximum_bytes_billed. It is not modified; query_parameters replace any parameters it already has.

    		 None
    project Optional[str]

    Project to run (and bill) the query job in. Defaults to the project the BigQuery object was created with. Tables in other projects can still be queried by their fully qualified names.

    		 None

    Examples:

    bq.execute( "SELECT * FROM project.dataset.users WHERE name = @name", query_parameters=[ bigquery.ScalarQueryParameter("name", "STRING", user_input) ], )

    Returns:

    Type Description
    QueryJob

    QueryJob An object of QueryJob.

    fetch_rows(query, query_parameters=None, job_config=None, max_results=None, *, project=None)

    Function runs a SQL statement and returns its rows.

    Unlike execute(), this uses the BigQuery jobs.query fast path, which runs short queries in a single request and returns the first page of rows with the response, instead of creating a job and polling it. Use execute() when you need the QueryJob (job ID, statistics, destination table); use this when you only need the rows.

    Parameters:

    Name Type Description Default
    query str

    BigQuery query string

    		 required
    query_parameters Optional[Sequence[QueryParameter]]

    Parameters referenced by the query as @name; see execute().

    		 None
    job_config Optional[QueryJobConfig]

    Extra job settings; see execute(). It is not modified.

    		 None
    max_results Optional[int]

    Maximum number of rows to return.

    		 None
    project Optional[str]

    Project to run (and bill) the query in; see execute().

    		 None

    Returns:

    Name Type Description
    RowIterator RowIterator

    The query's rows.

    get_table_in_project(project, max_workers=8)

    Function returns list of TableListItem objects of all the tables and views in a project.

    Tables are listed for up to max_workers datasets concurrently, instead of one dataset at a time, so a project with many datasets takes a fraction of the time.

    Parameters:

    Name Type Description Default
    project str

    Project bound to the operation.

    		 required
    max_workers int

    Maximum number of datasets to list tables for at once. The default stays below the HTTP connection pool size of the underlying client.

    		 8

    Returns:

    Type Description
    list[TableListItem]

    List[TableListItem]: A list of object of BigQuery TableListItem, grouped by dataset in the order the datasets are listed.
